# Lista 01 – Exercícios em C

Primeira lista de exercícios desenvolvida em C durante os estudos de programação e Engenharia da Computação.

## 📚 Sobre

Esta lista contém **37 exercícios** desenvolvidos com o objetivo de praticar lógica de programação e os fundamentos da linguagem C.

Os exercícios são executados através do arquivo `main.c`, que funciona como um menu interativo. O usuário informa o número do exercício que deseja executar e o programa direciona a execução utilizando `switch case`.
